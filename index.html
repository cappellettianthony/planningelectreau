      Onglet modal = catégorie dans Affecter une tâche (Présences / Remplacement / Absences). Ouverture par défaut : Remplacement.

      Noms des équipes

      Modifiez le nom affiché de chaque équipe. L'identifiant interne (ex. team_1) ne change pas : plannings, roulements, RPL et liaisons restent intactes.

      Seuils d'effectifs globaux

      Seuil minimal d'agents par équipe

      Nombre minimum d'agents qui doivent rester dans une équipe. Si ce seuil est atteint, la suppression d'un agent est interdite (RE et Admin). Mettez 0 pour autoriser la suppression jusqu'à vider l'équipe.

      Visibilité par équipe

      Si cette option est activée, un agent (lecture seule) ne voit dans le planning que l'équipe (ou les équipes) à laquelle il est lié via son e-mail. Les RE et Admin continuent de voir toutes les équipes. Les fiches de remplacement restent visibles pour tous dans le panneau latéral et via « Se porter volontaire ».

      Deadline de traitement des fiches RPL

      Nombre de jours avant la date du remplacement proposés par défaut comme date limite de traitement de la fiche. Le panneau latéral passe en jaune la veille de cette date limite.

      Marquage « Vu » des fiches RPL

      Définissez à quel moment une fiche de remplacement est considérée comme consultée (vu) par l'utilisateur connecté et les agents liés à son e-mail.

      Le clic simple continue d'amener à la date dans le planning. Le double-clic ouvre toujours la fiche détaillée.

      Le mode « survol » ne s'applique qu'à la liste de la fenêtre Se porter volontaire (pas au panneau latéral).

      Compétences recommandées pour les fiches de remplacement

      Cochez les compétences qui pourront être proposées comme « recommandées » lors de la création d'une fiche RPL. Seules les compétences cochées ici apparaîtront comme cases à cocher dans la fenêtre de date limite.
